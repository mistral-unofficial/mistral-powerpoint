Mistral for PowerPoint

A PowerPoint add-in that lets Mistral read, write and design your slides.

Download manifest

Install for yourself

  1. PowerPoint on the web: Home → Add-ins → More add-ins → My add-ins → Upload my add-in, then choose the downloaded manifest.
  2. PowerPoint for Mac: copy the manifest into ~/Library/Containers/com.microsoft.Powerpoint/Data/Documents/wef/ (create the folder if needed) and restart PowerPoint. The add-in appears under Home → Add-ins → My Add-ins.
  3. PowerPoint for Windows: put the manifest in a shared network folder, add that folder under File → Options → Trust Center → Trusted Add-in Catalogs, restart PowerPoint and pick it under Add-ins → Shared Folder.

Install for your organisation

A Microsoft 365 admin can upload the manifest under Admin center → Settings → Integrated apps → Upload custom apps and assign it to users or groups. It then appears for them automatically.

First start

Open Home → Mistral, click ⚙ and paste your own API key from console.mistral.ai. The key stays on your machine; requests go directly to the Mistral API.
